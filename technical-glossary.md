# DeadLockLens – Technical Glossary

## Introduction

This glossary explains important technical terms related to DeadLockLens and deadlock management.

## Key Terms

### 1. Process
A program currently being executed by the operating system.

### 2. Resource
A system component required by a process to perform its operations.

### 3. Resource Allocation
The assignment of a resource to a process.

### 4. Resource Request
A request made by a process to obtain a resource.

### 5. Deadlock
A condition in which two or more processes wait indefinitely for resources held by one another.

### 6. Resource Allocation Graph
A directed graph representing processes, resources, allocation relationships, and resource requests.

### 7. Victim Process
The process selected for recovery to help resolve a deadlock.

### 8. Rollback Cost
The estimated cost associated with reverting a process to an earlier state.

### 9. Protection Score
A numerical score calculated using process progress, rollback cost, and retry count.

### 10. Recovery
The process of resolving an existing deadlock through an appropriate recovery action.

### 11. PostgreSQL
A relational database management system used to store DeadLockLens data.

### 12. Cytoscape.js
A JavaScript library used for graph visualization.

### 13. Express.js
A Node.js web framework used to build backend APIs.

### 14. Referential Integrity
A database property maintained through relationships and constraints such as foreign keys.

## Conclusion

Understanding these terms helps users understand the concepts and technologies involved in DeadLockLens.
