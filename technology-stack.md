# DeadLockLens – Technology Stack

## Introduction

DeadLockLens uses a combination of frontend, backend, database, and visualization technologies to provide deadlock detection and analysis.

## 1. HTML

HTML is used to structure the web pages and application interface.

## 2. CSS

CSS is used to style the application and improve its visual presentation.

## 3. JavaScript

JavaScript handles frontend interactions and client-side functionality.

## 4. Node.js

Node.js provides the server-side JavaScript runtime for the backend application.

## 5. Express.js

Express.js is used to build backend routes and handle HTTP requests.

## 6. PostgreSQL

PostgreSQL stores process information, resources, allocations, requests, and deadlock event records.

## 7. Node-postgres (pg)

The pg library provides connectivity between the Node.js backend and PostgreSQL database.

## 8. Cytoscape.js

Cytoscape.js is used to visualize graph-based relationships between processes and resources.

## 9. Git and GitHub

Git manages source code versions, while GitHub hosts the repository and supports collaborative development.

## Conclusion

The selected technology stack provides the foundation for the development, visualization, and database management of DeadLockLens.
